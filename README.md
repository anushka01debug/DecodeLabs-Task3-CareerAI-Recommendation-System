# 🚀 CareerAI – Intelligent Career Recommendation & Skill Gap Analysis Platform

CareerAI is an AI-powered career guidance platform that analyzes a user's skills and resume to recommend suitable technology career paths, identify skill gaps, and generate personalized learning roadmaps.

The system combines Resume Parsing, TF-IDF Vectorization, Cosine Similarity, Interactive Analytics, and AI-powered career insights to help users make informed career decisions.

## 📌 Project Overview

Choosing the right career path can be overwhelming for students and early professionals. CareerAI simplifies this process by:

- Analyzing resumes automatically
- Extracting technical skills
- Matching profiles against multiple career domains
- Identifying missing skills
- Providing structured learning roadmaps
- Offering AI-powered career recommendations

---

## ✨ Core Features

### 📄 Resume Parsing
- Upload PDF or TXT resumes
- Automatic text extraction using PyPDF
- Intelligent skill detection

### 🎯 Career Recommendation Engine
- TF-IDF based feature extraction
- Cosine Similarity matching
- Top career recommendations ranked by compatibility

### 📊 Interactive Analytics Dashboard
- Career Match Leaderboard
- Skill Distribution Analysis
- Domain Strength Radar Chart
- Career Fit Visualization

### 🧠 Skill Discovery Quiz
- Interactive onboarding questionnaire
- Automatic technical profile generation
- Beginner-friendly career exploration

### 🛠️ Skill Gap Analysis
- Compare current skills with target role requirements
- Highlight missing competencies
- Prioritize learning objectives

### 📅 Personalized Learning Roadmap
- 12-week structured roadmap
- Weekly learning milestones
- Career transition guidance

## 📈 Machine Learning Approach

### Skill Representation

The system converts user skills and career requirements into numerical vectors using:

- TF-IDF Vectorization

### Career Matching

Similarity is computed using:

- Cosine Similarity

This enables efficient matching between user profiles and career skill requirements.
